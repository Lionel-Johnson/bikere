# BIKERE APP

## Project Overview
This project is a full-stack application for managing bike rentals.

## Setup
### Backend
1. Navigate to `backend`
2. Run `npm install`
3. Start the server using `npm start`

### Frontend
1. Navigate to `frontend`
2. Open `index.html` in a browser to view the app.

### Docker
Run `docker-compose up` to start the application in Docker.
